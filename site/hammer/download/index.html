apt

Debian, Ubuntu и Mint

Подключите репозиторий один раз — дальше лаунчер обновляется вместе с системой. Пакеты для amd64 и arm64.

Терминал 
# ключ репозитория
curl -fsSL https://hammer.veyron.online/apt/horizon-hammer.gpg | sudo tee /usr/share/keyrings/horizon-hammer.gpg >/dev/null
# сам репозиторий
echo "deb [signed-by=/usr/share/keyrings/horizon-hammer.gpg] https://hammer.veyron.online/apt stable main" | sudo tee /etc/apt/sources.list.d/horizon-hammer.list
sudo apt update && sudo apt install prismlauncher-horizon

Первый запуск

Три шага до игры

Скачайте

Файл для вашей системы — кнопкой вверху страницы, или любой из списка.

Войдите

Аккаунт Microsoft с купленным Minecraft. Файлы игры готовятся из вашей копии.

Создайте сборку

«Добавить экземпляр» → раздел Horizon → «Minecraft (Rust)», выберите версию и запускайте.

Сборки пока не подписаны: при первом запуске Windows SmartScreen и macOS Gatekeeper спросят подтверждение. Исходный код лаунчера · GPL-3.0

Ядро модов

Horizon Hammer — прямо из лаунчера

Сборка игры с ядром ставится так же, как обычный Horizon: скачивать вручную ничего не нужно.

Откройте

«Добавить экземпляр» → раздел Horizon → «Minecraft (Rust)».

Выберите ядро

Внизу, в «Загрузчик модов», отметьте Horizon Hammer и сборку.

Запускайте

Лаунчер скачает сборку и подготовит файлы игры из вашего Minecraft.
