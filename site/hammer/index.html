Моды, которым можно доверять

Ядро модов для Horizon — Minecraft: Java Edition, переписанного на Rust. Каждый мод живёт в песочнице WebAssembly, ставится одним файлом и перезагружается за секунду, не выходя из мира.

Зачем

      
То, чего нет у привычных загрузчиков

      
Forge и Fabric запускают моды как обычный Java-код с полным доступом к компьютеру. Здесь мод — гость.

      

        

          Песочница
Мод не видит ваши файлы и сеть. Что ему можно, написано рядом с его переключателем.

        

          Перезагрузка за секунду
Пересобрали — игра подхватила. Для установленных модов есть /hmod reload.

        

          Один файл
Положили .hmod в папку и включили. Ничего не компилируется на вашей машине.

        

          Сбой — дело мода
Упавший или зависший мод останавливается сам. Игра и остальные моды работают дальше.

        

          Всё привычное
Блоки, предметы, мобы, механизмы с энергией и жидкостями, окна, события, генерация мира.

        

          Тесты без игры
cargo horizon-mod test гоняет сценарии в той же песочнице, без окна и без мира.

      

    


    

      

        

          
Для игроков

          
Вы решаете, что можно моду

          
    
            
  • Новые моды выключены. Включаете сами, увидев, что им разрешено.
    • 
            
  • Разрешения — простыми словами: «видит вашу позицию», «рисует текст на экране».
    •

Для авторов

      
Мод — это обычный Rust

      
Манифест говорит, что моду нужно, код говорит, что он делает. Вот мод целиком: алмазный блок не сломать.

      

        

          
          
        


use horizon_mod_sdk::server::{BlockPos, Player, Registration, ServerMod, players};

struct BlockGuard;

impl ServerMod for BlockGuard {
    fn init() -> Result<(Self, Registration), String> {
        Ok((BlockGuard, Registration::new().on_blocks()))
    }

    // true — блок остаётся на месте
    fn break_block(&mut self, player: &Player, _pos: BlockPos, state: &str) -> bool {
        let guarded = state == "minecraft:diamond_block";
        if guarded {
            players::tell(&player.id, "This block is guarded");
        }
        guarded
    }
}
horizon_mod_sdk::export_server_mod!(BlockGuard);


id = "block_guard"
name = "Block Guard"
version = "0.1.0"

capabilities = ["players"]

      

    


    

      
Начать

      
Первый мод за десять минут

      
Нужны Rust и собранный Horizon.

      

        
Установите
rustup target add wasm32-unknown-unknown, затем cargo install --git https://github.com/artemspt/horizon-hammer-core --branch api/extra-100 cargo-horizon-mod

        
Создайте
cargo horizon-mod new my-mod — манифест, код и пример теста.

        
Запустите
cargo horizon-mod run. После каждой правки — build, игра перезагрузит мод сама.

Вопросы

      
Часто спрашивают

      

        
Запустятся ли моды для Forge, Fabric или NeoForge?
          
Нет: их код вызывает Java-классы Minecraft, которых в Horizon нет. Переносятся данные и ресурсы из jar — рецепты, теги, текстуры, модели.

        
Нужен ли купленный Minecraft?
          
Да. Horizon не содержит файлов Minecraft и готовит их из вашей копии игры при первом запуске.

        
Может ли мод навредить компьютеру?
          
Обычный мод — нет: он работает в песочнице и получает только то, что указано в манифесте и что вы разрешили. Исключение — нативные платы с пометкой [UNSAFE], у них полный доступ.

        
Чем это отличается от Horizon?
          
Horizon перешёл на нативные моды, которые правят исходники и требуют пересборки игры. Этот форк сохраняет песочницу: мод — один файл, который ставится без компиляции и перезагружается на лету.

        
Работают ли моды в мультиплеере?
          
Да. Серверные моды работают в одиночной игре, по LAN и на выделенном сервере; клиентские — в окне игрока. Мод может состоять из двух половин, которые общаются по своему каналу.

        
На каком языке писать моды?
          
Сейчас SDK есть для Rust. Мод собирается в WebAssembly-компонент, так что другие языки возможны, но готового SDK для них пока нет.
