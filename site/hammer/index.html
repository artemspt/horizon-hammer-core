Моды, которым можно доверять

Horizon Hammer — ядро модов для Horizon, Minecraft: Java Edition, переписанного на Rust. Каждый мод работает в песочнице WebAssembly и делает только то, что вы ему разрешили.

Сделать первый мод Документация

Зачем

То, чего нет у привычных загрузчиков.

  1. ПесочницаМод не видит ваши файлы и сеть, пока вы не разрешили. Что он может, написано рядом с его переключателем.
  2. Один файлПоложите .hmod в папку horizon-mods и включите в настройках. Ничего не компилируется на вашей машине.
  3. Перезагрузка за секундуПересобрали мод — игра подхватила его, не выходя из мира. /hmod reload делает то же для установленных модов.
  4. Сбой — это сбой модаУпавший мод останавливается сам, игра и остальные моды продолжают работать.
  5. Привычные возможностиБлоки, предметы, мобы, механизмы, окна, события, генерация мира, сеть между клиентом и сервером.

Первый мод

Нужны Rust и собранный Horizon.

# один раз
rustup target add wasm32-unknown-unknown
cargo install --git https://github.com/artemspt/horizon-hammer-core cargo-horizon-mod

# новый мод
cargo horizon-mod new my-mod
cd my-mod
cargo horizon-mod run     # собрать и запустить игру с модом
cargo horizon-mod build   # после правки: игра перезагрузит мод сама
cargo horizon-mod test    # сценарии из tests/ без игры

Полное руководство и справочник API — в docs/mods.md.

Играть с модами

  1. Положите файл.hmod в папку horizon-mods рядом с options.txt.
  2. Посмотрите, что ему можноНастройки → Моды показывают разрешения каждого мода. Новые моды выключены.
  3. ВключитеЕсли мод не загрузился, причина видна в его строке.

Неофициальный форк Horizon, не связан с его авторами и с Mojang или Microsoft. Файлы Minecraft не распространяются: игра готовит их из вашей копии.
